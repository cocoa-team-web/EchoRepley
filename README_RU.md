# Echo Replay Engine — прототип для Geode / Geometry Dash Android

Это стартовый каркас проекта, а не гарантированно готовый к сборке релиз. Код Geode зависит от версии SDK и биндингов Geometry Dash. Проверьте проект на своей версии Geode SDK перед установкой в игру.

## Что внутри
- `mod.json` — пример метаданных мода; замените `GEODE_SDK_VERSION` на версию своего SDK.
- `src/main.cpp` — экспериментальный прототип записи позиций и отображения призрака.
- `CMakeLists.txt` — минимальная заготовка; если у вас уже есть проект Geode, лучше оставить его исходный `CMakeLists.txt`.

## Важно
1. Сначала сделайте копию своего рабочего проекта.
2. Не заменяйте существующий `CMakeLists.txt`, если текущий шаблон Geode уже собирается.
3. В `mod.json` замените `GEODE_SDK_VERSION` на реальную версию SDK.
4. Соберите для своей архитектуры Android через Geode CLI.
5. Если сборка не проходит, пришлите полный текст ошибки и исходный `CMakeLists.txt`.

Прототип не реализует надёжное обнаружение смерти/рестарта и может требовать адаптации под конкретные заголовки SDK. Запись координат не гарантирует точное воспроизведение физики.
